One single-line joke about office life (113 characters), written to make the AI judge laugh: IT hands out a mirror instead of a second monitor, and suddenly the whole open-plan office is watching itself pretend to work twice as fast.

## Run it

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt` (or `./output/entry.txt` when `/output` does not exist), exits 0, and writes byte-identical output on every run.
